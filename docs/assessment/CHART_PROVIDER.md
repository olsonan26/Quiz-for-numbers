# Proprietary Chart Provider

`costarProvider` implements a typed calculation, hypothesis, and trace boundary over the pinned source commit.

It returns five core numbers, Called Name, PMEI counts, founder-authored source meanings, machine-readable provenance, and separately structured HUE hypotheses. Each core value uses its corresponding source table. Called Name uses the source's distinct public-perception table rather than the generic name-number table.

The optional **Your numbers and your answers** section exposes the five core values, Called Name, PMEI letter counts/tone/cross/checksum, and readable match statuses. The section appears after practical behavioral results and starts collapsed. It does not write to scoring, confidence, contradictions, or recommendations.

The HUE mapping is flagged `founderInputRequired` because no approved mapping table was located. Timeline and sensitive source content are excluded from public V1.
