# Proprietary Chart Provider

`costarProvider` implements a typed calculation, hypothesis, and trace boundary over the pinned source commit.

It returns five core numbers, Called Name, PMEI counts, founder-authored condensed source meanings, machine-readable provenance, and separately structured HUE hypotheses. Raw input, calculations, source meanings, product mappings, questionnaire evidence, and final report interpretation remain separate.

The HUE mapping is flagged `founderInputRequired` because no approved mapping table was located. Timeline and sensitive source content are excluded from public V1.
