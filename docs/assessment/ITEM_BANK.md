# Item Bank

The bank contains 72 original, founder-project-owned pilot items: six for each of twelve constructs. Items carry construct/facet, context, mode wording, response type, scoring, goal priorities, licensing, reading-level note, social-desirability risk, chart links, and follow-up status.

All modes have explicit wording. No restricted assessment item was copied. Options include situational uncertainty, not observed, and prefer not to answer; those produce missingness rather than trait points.

Current counts:

- Candidate: 72
- Minimum path: 36
- Typical path: 42
- Maximum adaptive path: 48

The wording remains pilot material pending expert review, cognitive interviews, reading-level analysis, and item-behavior studies.
