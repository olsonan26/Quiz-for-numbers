# Contradiction Engine

V1 detects item-versus-item, baseline-versus-stress, and chart-versus-behavior contradictions. It records sources, severity, status, permitted explanations, and a transparent user narrative.

Strong divergence is not averaged away. Explanations are restricted to versioned categories such as context dependence, stress shift, competing needs, current state, role adaptation, and unsupported chart hypothesis. The engine never manufactures an explanation to preserve a proprietary claim.
