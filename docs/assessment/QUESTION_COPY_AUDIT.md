# Question Copy Audit

## Scope

This audit covers all 72 pilot items and all four assessment modes. The revision aims for familiar, concrete language while preserving every item ID, construct, current facet ID, evidence context, score value, score weight, goal priority, adaptive follow-up flag, and bank position.

Item wording is version `1.1.0`. “Approved” means approved for this plain-language pilot, not psychometrically validated. “Cognitive review” means the new wording is the closest plain-language expression of the existing intent, but a participant interview should confirm that the item is understood as intended.

## Observer wording decision

The former `observerPrompt()` performed mechanical pronoun replacement and produced the same generic “they” question for a child, partner, and other person. Version 1.1.0 authors each mode explicitly:

- self questions speak directly to “you”
- child questions name “your child” and use school, task, friend, and family examples where adult contexts would be unnatural
- partner questions name “your partner”
- other-observer questions name “this person”
- questions about inner experience use “seem,” visible behavior, or reported speech when an observer cannot know the experience directly

The scored and skipped option semantics are unchanged. Self-report uses “Not sure.” Observer modes use “Not sure / haven’t seen this.”

## Pre-existing measurement limitations

This copy pass deliberately does not change scoring.

1. Each construct currently gives all six items one generic facet ID even though `constructs.ts` declares four specific facets. Several items appear to target different declared facets.
2. Every scored option uses the same `-2` through `+2` direction. Some constructs combine adaptive behavior, difficult behavior, context change, and opposing strategies. Frequent endorsement can therefore raise the same composite for meanings that are not one psychological pole.
3. Several questions remain double-barreled because splitting them would alter the 72-item bank and adaptive coverage:
   - ITEM-01-05
   - ITEM-02-03
   - ITEM-06-03
   - ITEM-07-03
   - ITEM-09-02
   - ITEM-09-05
4. Context-variation items such as ITEM-07-06, ITEM-10-06, and ITEM-12-06 describe change, not a simple higher or lower trait.
5. Capability and comparison stems still need testing with the Almost never–Almost always response scale.

Highest-priority measurement review: HUE-06, HUE-07, HUE-09, HUE-10, HUE-11, and HUE-12. These limitations predate the wording update and must not be described as solved by simpler copy.

## Version and migration requirement

Every rewritten item is version `1.1.0`. The item-bank and assessment versions must also be bumped by the owning version/session change. An unfinished session created under the prior bank must not resume against these new prompts. Completed reports should retain their original version record.

## Validation still required

- Read every question aloud in all four modes.
- Run cognitive interviews across self, partner, and child-observer paths.
- Test whether the intended behavior is recalled consistently.
- Check whether observers use visible evidence rather than guessing private experience.
- Review double-barreled and directionally mixed items before calibration.
- Do not claim reliability, validity, or population norms from this copy review.
