# Confidence Model

Confidence combines scored coverage, consistency, baseline/stress stability, response quality, observer familiarity, current-state contamination, missingness, and contradiction penalties.

User labels are strong, moderate, tentative, conflicting, or insufficient. Internal values support deterministic thresholds and layout only; they are not calibrated probabilities and are never displayed as percentages.

Chart agreement does not increase behavioral confidence. Missing or uncertain responses cannot raise confidence, and strong contradiction blocks a strong classification.
