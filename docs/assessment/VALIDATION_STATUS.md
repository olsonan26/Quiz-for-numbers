# Validation Status

Instrument status: **developmental**.

The constructs and rules are research-informed, but the V1 item bank and combined proprietary layer have not completed cognitive interviews, usability pilots, reliability studies, observer-agreement studies, factor/internal-structure work, measurement-invariance work, criterion comparisons, incremental-validity tests, or practical-outcome studies.

No population is validated. The product must not be described as scientifically proven, clinically validated, diagnostic, predictive, or suitable for high-stakes decisions.
