# Known Limitations

- The original 72-item bank has not yet been cognitively interviewed or psychometrically calibrated.
- Internal score positions and confidence thresholds are engineering rules, not population norms or calibrated probabilities.
- Observer reports reflect one perspective and cannot reveal another person's inner state.
- Local browser storage is not encrypted.
- Browser print provides PDF output; no separate PDF generation service exists.
- Chart-to-HUE mappings await founder approval.
- Deeper name-engine letter/pair/trio rules remain unported.
- PMEI public founder prose is not exposed pending content review.
- No remote sync, account, multilingual content, formal screen-reader study, or real pilot analytics exists.
- The public Vercel release is manually deployed. Automatic GitHub-to-Vercel deployments require adding the repository owner's GitHub login connection to the Vercel account.
