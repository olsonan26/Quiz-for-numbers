# Human Pattern Profile V1

This directory is durable implementation memory for the complete local-first V1.

## What ships

- Four perspective modes and nine user goals
- 72 original candidate items with deterministic 36/42/48 adaptation
- Twelve behavioral constructs
- Baseline-versus-stress scoring, contradictions, confidence, interactions, and recommendations
- Pinned LOOKS-LIKE-COSTAR calculation/PMEI provider with visible source-specific meanings and traces
- Goal-first direct answers, progressive visual disclosure, and twelve accessible full-profile modules
- Deliberate Next/Previous, exact save/resume, JSON export, print/PDF, feedback correction, report deletion, and clear-all
- No AI, server, account, analytics, or remote storage

Run `npm install`, `npm run dev`, or the full gate with `npm run check && npm run test:e2e`.

Feedback Round 1 evidence is in `USER_FEEDBACK_ROUND_1.md`; the complete 72-question review is in `QUESTION_COPY_AUDIT.md`.
